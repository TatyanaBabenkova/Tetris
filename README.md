# Блок-пазл в дорогу - Попутчик

Первая локальная версия веб-игры для просмотра и обсуждения.

## Как открыть

Откройте `index.html` в браузере. Бэкенд не нужен.

Для проверки картинок после загрузки на GitHub Pages откройте `check-assets.html`. Если все строки показывают `OK`, все фоны лежат на месте.

## Что внутри

- `index.html` - страница игры.
- `styles.css` - адаптивный интерфейс.
- `game.js` - игровая логика, уровни, графика, звук и локальный рекорд.
- `check-assets.html` - проверка, что GitHub Pages видит все картинки.
- `GITHUB_UPLOAD.md` - короткая инструкция по структуре файлов для GitHub.
- `assets/title-splash.png` - главная картинка первой заставки.
- `assets/level-01-summer-meadow.png` ... `assets/level-10-space.png` - рисованные панорамные фоны уровней.
- PNG-файлы с префиксами `meadow-`, `forest-`, `village-`, `city-`, `sea-`, `mountain-` в папке `assets` - предметы для фигур первых шести уровней.

В игре используются стандартные тетромино: каждая фигура состоит из четырех квадратов. Фон движется цельной панорамой; клик или тап по свободному фону за окном останавливает или запускает движение вида.

## Маршрут уровней

1. Летний луг
2. Березовый лес
3. Деревня у реки
4. Большой город
5. Море
6. Горы
7. Снежный лес
8. Ночной город
9. Северное сияние
10. Космос

Сейчас для тестирования новый уровень открывается каждые 3 очищенные линии. На 10-м уровне игра остается в космосе и продолжается на максимальной скорости.

## Офлайн-режим

Игра не использует внешние библиотеки, CDN, шрифты, картинки, аналитику или API. В `index.html` добавлена политика `connect-src 'none'`, чтобы запретить сетевые подключения со страницы.

Рекорд, настройка звука и состояние движения фона сохраняются только в браузере на устройстве.
